A few things to know about your new gala buddy.

Can Gaile help with every NCR destination?

Gaile uses the app’s bundled NCR route pack for supported places and journeys. It does not cover every destination or provide live transport updates. Check the route report and dated sources in the app, and confirm current details before travelling.

What do I need for offline use?

Supported route data is included with the app. Ordinary route answers use those retrieved facts and local phrasing, without loading the assistant model.

For on-device example explanations, set up the separate local assistant in Settings → Offline resources. Download the approximately 491 MB model once, or import the matching GGUF file. Allow at least 560 MB of free space. The model is checked before use and kept in private app storage.

Does my conversation go to a cloud assistant?

Route retrieval and replies run locally. After setup, the assistant’s example explanations also run on your device. The app has no analytics, upload SDKs, or cloud fallback. The explicit model download needs internet; importing a matching local model does not.

Where can I get the Android APK?

Use View Android releases below to open the project’s GitHub releases page. Check the release notes and assets there for any published APK; this website does not verify an APK version or file size.

When installing an APK, Android may ask you to allow installation from the browser or file manager you use. Use the project’s release page as your source. Developers can find local build instructions in the project README.

What is still being built?

Basemaps, GPS integration, and persistent trip storage are not connected yet. Route information is not live travel guidance, and native model performance still needs phone testing. The commuter story above is illustrative and does not depict a real route or user interview.
