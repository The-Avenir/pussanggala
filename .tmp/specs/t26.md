## Fixture — `test/fixtures/eval-network.ts`
A fictional, clearly synthetic mini network (header comment-free; names like "Alpha Terminal", "Bayani Market", "Cedar Hospital", "Dalisay Station"…) built with `buildRawPack`. Must include at least:
- ~18–24 accepted places with aliases (several ≥5 chars for typo tests), 1 `outside` place, 1 place with `ncr: 'ambiguous'`, 1 ambiguous alias shared by 2–3 places, 2 places with no coords (unmapped).
- ~24–30 stops, accesses in all three directions incl. one excluded access and one place with only `to_stop` access (can be an origin but not a destination).
- ~12 routes: jeepney, modern_jeepney, uv_express, bus, tricycle, rail; one `suspended`, one `retired`, one status `unknown`.
- Directed legs incl. one-way services (no reverse), one excluded leg, missing ride_min on some legs.
- Walk links (one excluded), same-stop transfers, and a cross-thread join: two legs sourced from different reddit_thread sources joined at one stop (use `recordSources` overrides with sources `src_thread-a` / `src_thread-b`).
- Two places with nearly identical coordinates and similar names but NO connection between their stops.
- Fares: known, conflicting (two reports on one leg), and missing on some legs. Hours: single, conflicting, missing. Notes of each kind on legs and stops. Sources with old (2024) and recent (2026-09) posted_at and one null.

Keep a short markdown-free ASCII map of the network as an exported `NETWORK_DIAGRAM` string constant so reviewers can check expectations by hand.

## Cases — `test/eval/route-cases.test.ts`
Table-driven, ≥30 positive route cases (expected to return `status:'ok'`), each stating `{name, from, to, preference, expectSteps?: string[] /* exact step ids of itineraries[0] */, expectContains?: string[][] /* step-id lists that must appear among itineraries */, expectRides?: number}`. Derive every expectation by hand from your fixture spec — never by printing `route()` output and pasting it. Cover: direct rides of every mode; same-stop transfers; walk-link transfers; the cross-thread join; 2- and 3-ride trips; preference changes reordering the first itinerary (lowest_fare vs fewest_transfers vs shortest_reported_time); unknown-fare option still present under lowest_fare; reverse trips that exist via distinct reverse legs.

## Negative/edge cases — `test/eval/negative-cases.test.ts`
- Resolution: each ambiguous alias → clarification 2–4 candidates with area; outside place → outside_ncr; ncr-ambiguous → ncr_unresolved; typo (1 edit on ≥5-char alias) → intended place in top 3 (≥5 different aliases); unknown arbitrary address → unsupported with no auto-pick.
- Routing: disconnected pair → `no_route`; destination-only-to_stop place as destination → `no_destination_access`; excluded access; suspended route never appears in any itinerary for any place pair (assert over ALL accepted pairs); retired likewise; excluded leg/walk never appear (all pairs); the near-identical-coordinates pair → no_route; one-way service reverse → no_route or an itinerary without that leg; no itinerary anywhere has >4 legs or a repeated stop (all pairs).
- Unknowns/conflicts: an itinerary with a fare-less leg has `fare.status === 'unknown'`; conflicting fares → `conflict: true`; no card anywhere shows a fare amount of 0 unless the fixture has an explicit 0 report (it should not); comparisons never name an unknown-value option as winner.
- Cards/context (injected `now = new Date('2026-10-09T00:00:00Z')`): stale warning on 2024 sources, none on 2026-09 sources, `source_date_unknown` for the null one; every card recordId and bundle allowedRecordId exists in the pack; bundle bounds respected.
- Hours: conflict, unknown, reported statements on fixture routes.
- End-to-end Taglish: ≥6 queries through `parse` → `resolve` → `applyIntent` → `route` → `compose` → `buildContext` (e.g. "galing Alpha Terminal papunta sa Cedar Hospital", "paano pumunta sa X galing Y?", "X to Y pinakamura", follow-up "pabalik" rerouting directed records, "sa Z na lang", "anong oras last trip" → answerHours for selected routes).
- Restoration: route → save ref → rebuild pack with that leg removed → `record_missing`; with its route suspended → `service_suspended`.
