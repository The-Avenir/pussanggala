## `src/cards/sources.ts`

## `src/cards/compose.ts`
`compose(itinerary: Itinerary, pack: Pack, now: Date): Card[]` — exactly one card per `itinerary.ref.steps` entry, `cardId = cardId(itinerary.id, index)`.
- PointView for a stop: `{stopId, placeId: stop.place_id, name: stop.name, landmarkHint (omit if empty), mapped}`; for a place: `{placeId, name}` + mapped. `mapped` = place has lat/lng and `mapping_status === 'mapped'` (a stop uses its place).
- access card: `direction` 'start' for step 0, 'end' for the last step; place + stop; walkText, walkMeters/walkMinutes as Known; records: place_stop + place + stop.
- ride card: routeId, mode, signboard (omit if null), directionLabel, board/alight PointViews, rideMinutes Known, `fares` = all FareViews for the leg (each with its own `sources`), `hours` = HoursViews for the route (each with sources), notes = notes linked to the leg, then to the board stop, then the alight stop (dedupe, keep that order, then id). records: leg, route, both stops, fares, hours, notes.
- walk card: from/to PointViews, walkText, Known walk values, notes linked to from/to stops. records: walk_link + stops + notes.
- Card `sources` = sourceRefs over the card's records; `recordIds` = sorted unique record IDs.
- Warnings (fixed English messages; never use the words "verified", "confirmed" or "current"):
  - `fare_unknown` (ride with no fare reports): "No fare reported for this ride."
  - `fare_conflict` (>1 distinct (min,max) report): "Fare reports differ; each report is shown with its source date."
  - `time_unknown` (ride_min null on ride; walk_min null on walk/access): "Travel time not reported."
  - `service_status_unknown` (route status `unknown`): "Service status not reported in recent sources."
  - `unmapped_point` (any PointView with mapped=false): "Location not mapped; shown in the schematic only."
  - `schematic_only` (ride/walk without a `source_path` shape): "Map connector is schematic, not the actual vehicle path."
  - `stale_source` (any card source stale): "Source post is older than N days (source post date YYYY-MM-DD)." using the oldest stale source and manifest stale_after_days.
  - `source_date_unknown` (any card source without posted_at): "Source post date unknown."
  Each warning's `recordIds` = the records that triggered it. Order warnings by the order above.
- Card notes are `NoteView {noteId, kind, body, sources}`.

## `src/context/build.ts`
`buildContext(input: {trip: TripState; cards: Card[]; itineraries: Itinerary[]; comparisons: ComparisonStatement[]; hourStatements: HourStatement[]}, pack: Pack): EvidenceBundle`
- `cards` = first `EVIDENCE_BOUNDS.maxCards` cards in order.
- `alternatives` = up to `maxAlternatives` itineraries whose id is not the cards' itinerary (cards[0].cardId before '#'), mapped to `{id, rideCount, transferCount, fare, reportedRideMinutes}`.
- `notes` = dedupe of notes from included cards in card order; then notes linked (noteIdsByStop) to any stop referenced by included cards that are not already present, sorted by kind `warning > conflict > tip` then id; cap `maxNotes`. Each with sources (use `sourceRefs`, `now` is not needed for notes — pass the latest date available: add a `now: Date` field to the input object instead, and use it everywhere).
- comparisons limited to those whose winner and compared ids are within the included itinerary ids (selected + alternatives).
- `allowedCardIds` = included card ids; `allowedRecordIds` = sorted unique of included cards' recordIds + included itineraries' recordIds + hourStatements' report ids/route ids + note ids.
- `packId` = pack.manifest.pack_id, `v: 1`, `trip` as given.
